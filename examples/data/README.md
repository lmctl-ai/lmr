# Tutorial fixtures

These compact CSV fixtures contain original synthetic observations, generated locally with Python's `random.Random(2718)` and simple model formulas; they were not downloaded or copied from teaching datasets. `tut-cars.csv` mimics correlated fuel-economy/weight/power measurements, while `tut-counts.csv` mimics a low-count exposure trend. Other tutorials generate their input vectors in lmscript with the fixed seeds in their headers.
